# Snipcraft

System-wide text expansion for Android. Local. Fast.

Type a shortcut, get your snippet — anywhere you can type.

## Status

`v0.1.0-dev` — Project scaffolding in progress.

## Requirements

- Android 12+ (API 31)
- Accessibility Service permission

## Building

```bash
./gradlew assembleDebug
```
